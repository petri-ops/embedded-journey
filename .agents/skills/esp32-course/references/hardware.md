# 硬件配置

## 主控板

- ESP32 DevKit：ESP32-D0WD-V3 芯片 / 4MB Flash / CP2102 串口芯片
- 串口 **COM7**（CP2102 驱动走 Windows Update 自带）
- 固件 MicroPython v1.29.0（备份在 `firmware/`）
- 局域网 IP 通常 192.168.0.105（DHCP，可能变化，连上后打印确认）
- 常用命令（mpremote 刷机/传文件）见 `esp32-course/00-课程总览.md`

## 安全红线（指导任何接线前必须核对）

1. **GPIO 是信号不是电源**：LED、数码管每段必串 ≥220Ω 电阻。历史事故：10-22 数码管未限流，3.3V 被拉垮触发 Brownout 无限重启
2. **避开 GPIO1/3**：被串口（REPL/刷机）占用，外接器件会丢串口
3. **避开 GPIO6-11**：接内部 Flash，碰了直接死机
4. **GPIO34-39 只能输入**：无输出能力、无内部上拉；按键上拉别选这些脚
5. **ADC2 与 WiFi 冲突**：GPIO0/2/4/12-15/25-27 属 ADC2，WiFi 开启后读不了；联网项目的模拟量（摇杆、光敏、LM35、声音）优先用 ADC1（GPIO32-39，34-39 仅输入）
6. **Strapping 引脚 0/2/12/15**：开机瞬间有启动功能，外接电路别把它们在开机时拉错电平（GPIO2 板载 LED 已占用，不影响）
7. **5V/3.3V 兼容**：模块先看是否宽电压。HC-SR04 为宽电压版（3-5.5V）可 3.3V 直连；继电器/舵机/步进电机逻辑脚可 3.3V 控制，但电源脚接 5V（VIN）
8. **断电接线**：接线、改线前先断 USB 电；上电前自查正负极和短路

## 引脚速记（随课程使用持续补充）

- GPIO2：板载 LED（已占用）
- 触摸脚 T0-T9 = GPIO 4/0/2/15/13/12/14/27/33/32
- 数码管历史接线（seg.py，共阳代码需改共阴）：a13 b12 c14 d27 e26 f25 g33 dp32
- 注意：seg.py 的段码表按共阳极编写，新套件数码管是**共阴**，0/1 需全部取反
