# 第 1 课：电子电路基础

> 目标：搞懂电流/电压/电阻的关系，能自己计算限流电阻，理解上拉电阻，并能独立推导数码管的正确接法。
> 本课知识直接对应实战翻车点：数码管 Brownout 事故。

---

## 0. 复习：欧姆定律（初中内容）

| 符号 | 名字 | 单位 | 水路比喻 |
|---|---|---|---|
| U | 电压 | 伏特 V | 水塔的高度（推力） |
| I | 电流 | 安培 A（常用 mA） | 水流的大小 |
| R | 电阻 | 欧姆 Ω | 水管的粗细（阻碍） |

```
U = I × R        R = U / I        I = U / R
```

初中默认电路里只有"理想电阻"这种乖学生。现实的 LED、按键、传感器各有脾气 —— 下面三个坑就是初中没讲的。

---

## 坑一：LED 不遵守[欧姆定律](词汇表.md#ohms-law)（非线性器件）

LED 是二极管，行为像一道水闸：

- 电压低于**[导通压降](词汇表.md#forward-voltage)** → 基本不导通，不亮
- 超过压降 → 闸门全开，**电流近乎无限上涨，自己完全不会节制**

常见 LED 导通压降：红/黄 ≈ 2.0V，蓝/白/绿 ≈ 3.0V。

### [限流电阻](词汇表.md#current-limiting)计算（两步走）

```
第1步：LED 固定吃掉压降 Vf（如红光 2.0V）
第2步：剩下的电压给电阻，用来限定电流

R = (电源电压 - Vf) / 目标电流
```

**例**：3.3V 供电、红色 LED、想要 20mA：

```
R = (3.3 - 2.0) / 0.02 = 1.3 / 0.02 = 65Ω   ← 最小值
```

阻值越大电流越小、越暗：

| 电阻 | 电流 | 效果 |
|---|---|---|
| 65Ω | 20mA | 安全上限 |
| **220Ω** | **≈5.9mA** | **推荐，亮度足够** |
| 1kΩ | ≈1.3mA | 微亮 |
| 0Ω 直连 | 几百 mA | 💥 烧毁 |

```
电路图：GPIO ──[220Ω]──▶|── GND     （▶| 是 LED 符号）
```

> 提示：为什么板载 LED（GPIO2）直连也没烧？开发板出厂已在回路里焊好了限流电阻。
> 板厂替你兜底的只有板上的东西，外接元件必须自己接电阻。

## 坑二：供电是有上限的（[Brownout](词汇表.md#brownout) 事故复盘）

每条供电路径都有天花板：

- 单个 GPIO：绝对极限 40mA，**长期建议 ≤ 20mA**
- 所有引脚总电流：百 mA 级上限
- 板载稳压器（5V→3.3V）：约 1A，还要养 CPU + WiFi
- WiFi 发射瞬间：300~500mA 峰值

### 数码管 Brownout 复盘

```
无电阻时：每段电流无上限（几十 mA+）× 8 段齐亮
        → 总电流远超供给
        → 3.3V 被拉到 2.8V 以下
        → ESP32 检测到电压崩溃，主动复位保命
        → 开机瞬间再次崩溃 → 无限重启循环

串口表现：E BOD: Brownout detector was triggered（刷屏）
```

**结论：芯片没坏，是保护机制在忠实地工作。** 记住：GPIO 传递的是**信号**，不是电源。大电流设备（大功率灯、电机、继电器）要靠三极管/MOSFET 当开关，让外部电源干重活（后续课程）。

## 坑三：[功率](词汇表.md#power)（Power）—— 电阻也会累

电阻限流时自己发热：**P = U × I**

本课场景：1.3V × 5.9mA ≈ **8mW**，小电阻（1/4W = 250mW）毫无压力。
但做大电流项目（电机、电源）前必须先算功率账，否则电阻烧黑冒烟。

## 5. [上拉电阻](词汇表.md#pull-up)（Pull-up Resistor）：输入世界的地基

**输出** = 引脚主动给电平；**输入** = 引脚读外部电平。

输入的大坑：**[悬空](词汇表.md#floating)（floating）** —— 什么都不接的输入脚像天线，干扰一来 0/1 乱跳，"按键没按它自己触发"。

解法：用电阻给引脚一个**默认立场**：

```
        3.3V
         │
       [10kΩ]  ← 上拉电阻（默认拉成高电平 1）
         │
GPIO ────┤
         │
       [按键]
         │
        GND   ← 按下：引脚直通 GND，读 0
```

- **松开**：引脚经 10kΩ 连 3.3V → 读 **1**
- **按下**：引脚直连 GND → 读 **0**（"按下是 0" = **[低电平有效](词汇表.md#active-low)**，与[共阳](词汇表.md#common-cathode)数码管"低电平点亮"同思路）

为什么是 10kΩ？太大拉不住干扰，太小白白耗电。

MicroPython 一行启用内部上拉：

```python
btn = machine.Pin(0, machine.Pin.IN, machine.Pin.PULL_UP)
# btn.value()：松开 = 1，按下 = 0
```

> 板子上的 BOOT 键就是接在 GPIO0 上，用的正是这套电路。

对称地还有**下拉电阻**（默认 0、按下变 1），后面按键课会用。

## 6. [分压器](词汇表.md#voltage-divider)（Voltage Divider）：所有模拟传感器的通用原理（第 3 课伏笔）

两个电阻串联，中间取电压：

```
Vin ──[R1]──┬──[R2]── GND
            │
           Vout = Vin × R2 / (R1 + R2)
```

电位器、光敏、热敏本质全是"电阻会变的分压器"：
物理量变化 → 电阻变化 → 分压比变化 → ADC 读到的电压变化。

## 7. 实战验收：[数码管](词汇表.md#seven-segment)正确接线（自己推出来）

```
                数码管（共阳，俯视引脚图）
                ┌─────────────┐
   段a e ─[R]──┤ 12  11  10   │
   段f d ─[R]──┤ 9   8   7    │      8、3 脚 = 公共阳极
   段g c ─[R]──┤ 6   5   4    │      （接 3.3V）
   段dp b ─[R]─┤ 2   1        │
                └─────────────┘
                 3V3 ────────┘（公共脚）
```

接法清单：

1. **公共脚（第3、8脚）→ 3.3V**
2. **每个段脚 → 220~470Ω 电阻 → GPIO**

对应关系（b 段建议换引脚，见下）：

| 段 | a | b(注1) | c | d | e | f | g | dp |
|---|---|---|---|---|---|---|---|---|
| GPIO | 13 | 12→16 | 14 | 27 | 26 | 25 | 33 | 32 |

- **注1** GPIO12 是**[启动配置引脚](词汇表.md#strapping-pin)（strapping pin）**：外接电路若在开机时呈高电平，芯片会把 Flash 电压配成 1.8V 导致启动失败。建议 b 段改接 GPIO16，代码里 `b = machine.Pin(16, ...)` 一行即可。
- 电流验算：8 段全亮 × 5.9mA ≈ 47mA，安全（47mA < 100mA 上限）
- 代码不用改：共阳低电平点亮，现有段码表本来就对。

## 课后题

1. 用 5V 供电、蓝色 LED（压降 3.0V），想要 10mA 电流，该串多大电阻？
2. 上拉接法下，为什么按键"按下"读到的是 0 而不是 1？
3. 把 220Ω 误用成 22Ω，会发生什么？（定性回答）

## 参考答案（先自己做完再看！）

<details>
<summary>点开查看答案</summary>

1. **R = (5 − 3.0) / 0.01 = 200Ω**。剩余电压 2.0V 全部交给电阻，200Ω 时电流恰好 10mA。
2. 按下时按键把引脚**直接短路到 GND**。引脚的电压由最"强硬"的连接决定：直连 GND（0Ω）完胜经过 10kΩ 的 3.3V，所以读到 0。低电平有效接法的代价是按下瞬间有 3.3V/10kΩ ≈ 0.33mA 的小电流流过，无害。
3. 电阻缩小 10 倍 → 电流约 10 倍（≈59mA），**超过 GPIO 20mA 安全线**。轻则发热降寿命，重则烧毁该引脚（GPIO 损坏是永久性的）。亮度提升其实有限（人眼对亮度不敏感），纯属亏本操作。
