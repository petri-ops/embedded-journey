## 三、概念误区（错题本·概念篇）

操作类失误见 `00-课程总览.md` 踩坑表，这里记"想法错在哪"。

| 日期 | 误区 | 更正 |
|---|---|---|
| 10-26 | 开发板要像电脑一样"装系统"才能变强 | 固件已含 FreeRTOS；变强靠加库、换固件、加硬件 |
| 10-22 | LED/数码管直接接 GPIO 就能亮 | GPIO 是信号不是电源，必串 ≥220Ω（同踩坑表） |
| 10-26 | WiFi 密码进了公开仓库也"不用担心" | 方向对（需攻击者物理靠近，非全球可利用）但结论过头：SSID+密码成对泄露 = 附近的人可精确匹配入网；且"凭据不进版本库"是工程铁律——将来 MQTT/API token 是远程有效的 |

## 五、距离成熟工程师多远

**长期目标（10-26 确立）**：做出工业级产品。
**当前位置**：入门学习者（阶段 0 中段）
路线定位：入门学习者 → 能独立做项目的爱好者 → 准工程师 → 初级嵌入式工程师 → 成熟工程师 → 工业级产品

与成熟工程师的主要差距（按重要性排序）：

1. **C 语言与底层**——目前隔着 MicroPython 抽象层，没碰过寄存器和真裸机
2. **RTOS 实操**——概念懂了，任务/队列/信号量还没用过
3. **读手册能力**——还不会独立看 datasheet/模块手册决定接线
4. **工程工具链**——Git、断点调试、构建系统都还没用
5. **项目量**——还没有一个完全独立完成的完整项目

业余节奏粗估：阶段 0 收尾约 1-2 个月；到准工程师约 3-6 个月；到初级嵌入式工程师水平约 6-12 个月。数字仅作参考——**持续比快重要**。

## 六、成长路线（四阶段）

| 阶段 | 内容 | 毕业标准 |
|---|---|---|
| **0 课程通关**（当前，~1-2 月） | 第 1-5 课 + 结业项目，36 项配件轮一遍 | 不看笔记独立做出"传感器→ESP32→网络→执行器"完整系统 |
| **1 独立项目**（~1-2 月） | 自选真实需求（门磁报警/桌面气象站/红外云台任选）；学 Git、查资料、读模块手册 | 独立交付一个"别人真的在用"的东西，代码进 Git 仓库 |
| **2 深入底层**（~2-4 月） | C 语言 → Arduino/ESP-IDF；FreeRTOS 任务/队列/信号量实操；低功耗 | 用 C 写出多任务采集+联网程序 |
| **3 工程师化·工业级**（长期，方向已明确） | PCB/焊接/电源设计；可靠性工程（宽温、EMC、认证 CE/FCC）；OTA/量产；实时控制与工业协议（Modbus 等）；看门狗与失效保护 | 交付一台能长期稳定运行的工业级设备 |
