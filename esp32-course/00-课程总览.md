# ESP32 + MicroPython 学习课程

> 学习方式：ZCode 讲解 → 实操验证 → 本目录归档笔记
> 课程管理：本项目由 `.agents/skills/esp32-course` 技能驱动（说"上课 / 下一课 / 看进度 / 交作业 / 记录踩坑"即可）
> 硬件：ESP32 DevKit（ESP32-D0WD-V3, 4MB Flash, CP2102 串口）｜ 配件：进阶版套件 36 项（见 [配件清单](配件清单.md)）
> 固件：MicroPython v1.29.0 ｜ 串口 COM7 ｜ 局域网 IP 192.168.0.105（DHCP，可能变化）

> 📄 **文档格式说明**：每课同时保存 `.md`（编辑源码）和 `.html`（分享版）。
> `.html` 是单文件、无依赖，双击浏览器打开即可，也可直接发给朋友。
> 修改 `.md` 后在本目录运行 `python build_html.py` 重新生成。

## 本目录其他文件（代码实践区）

- `../esp32/main.py` —— 网页控制 LED 的常驻服务（开机自启）
- `../esp32/wifi_config.py` —— WiFi 密码配置（**不入库**；首次使用复制 `wifi_config.example.py` 并上传到板子）
- `../esp32/seg.py` —— 数码管段码程序（待硬件修复后验证）
- `../esp32/led.py` `pwm.py` `wifi.py` —— 练手代码备份
- `../firmware/ESP32_GENERIC-20260824-v1.29.0.bin` —— 固件备份
- `成长档案.md` —— 概念追踪、提问日志、能力雷达、成长路线（skill 每次会话维护）

## 常用命令备忘

```bash
# 上传文件到板子
python -m mpremote cp D:/1.WorkDir/PLC/esp32/main.py :main.py

# 重启板子
python -m mpremote reset

# 直接在板子上运行本地脚本（不保存）
python -m mpremote run D:/1.WorkDir/PLC/esp32/seg.py

# 烧录固件（恢复出厂 MicroPython）
python -m esptool --port COM7 erase-flash
python -m esptool --port COM7 --baud 460800 write-flash 0x1000 D:/1.WorkDir/PLC/firmware/ESP32_GENERIC-20260824-v1.29.0.bin
```
